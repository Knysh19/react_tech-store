# Tech Store

Tech Store is a web application for browsing and filtering products with basic e-commerce functionality.

---

## 🚀 Live Demo

https://react-tech-store-silk.vercel.app/

---

## 🧠 Overview

The application allows users to explore a catalog of products, filter them by different criteria and manage a simple shopping cart.

---

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* SCSS

---

## ⚙️ Features

* Product catalog
* Filtering and sorting
* Product details page
* Shopping cart
* Responsive layout

---

## 📁 Project Structure

```text
src/
  components/
  pages/
  utils/
public/
```

---

## 📌 Notes

* This project focuses on frontend architecture and state management
* Data is provided via local JSON
* Designed as a practice project to simulate a real e-commerce interface
